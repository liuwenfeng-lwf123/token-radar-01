How the number is built

TVL, 7-day growth, listing date and chains all come from the snapshot. The category multiple is the sector's launch value per TVL dollar: RWA 0.35, lending and derivatives 0.30, DEXs 0.28, bridges 0.18, everything else 0.22. Growth is clamped to −50%…+100% and counts at 60% weight. Age is days since DefiLlama first listed the protocol, capped at 3 years; an unknown listing date counts as 365 days. Each extra chain adds 3%, up to 12%.

Watchlist means “DefiLlama records no token” — not “definitely no token”. A protocol on the list may still have a token its DefiLlama record does not carry. Implied value is this radar's own estimate, never a price and never a promise that a token launches.
